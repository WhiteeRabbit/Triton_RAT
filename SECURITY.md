# Triton RAT Security Policy

## 1. Project Purpose
Triton RAT is a remote administration tool designed **only for managing your own devices**.  
It is **not intended** for unauthorized access to other people's computers.

## 2. Responsible Usage
- You are allowed to use this tool **only on your own computers** or with **explicit permission** from the owner.  
- Any **malicious use** (data theft, unauthorized access, etc.) is strictly prohibited.  
- The user is solely responsible for how they use this tool.

## 3. Disclaimer
This software is provided **"as is"** without any warranty.  
The developer **is not responsible** for any consequences of misuse, including legal issues.

## 4. Reporting Security Issues
If you find any vulnerabilities or security issues, please open an **Issue** in the repository or contact me via GitHub.
